# Security

Please report a security problem privately, not in a public issue:

- by email: [hello@wirecat.dev](mailto:hello@wirecat.dev);
- or through [GitHub's private vulnerability reporting](https://github.com/WireCatLabs/cli-messaging/security/advisories/new).

Say what you saw, how to repeat it, and which version. Never send a session file, a token or
someone's messages.

What the tools built on this package keep on your computer, and what stops an agent from sending:
[wirecat.dev/en/docs/security](https://wirecat.dev/en/docs/security).
